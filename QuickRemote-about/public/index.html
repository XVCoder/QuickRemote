项目介绍

QuickRemote 通过自建中转服务器全量转发 RDP 流量，让安卓手机随时随地安全连接家中的 Windows 电脑。PC 端安装客户端并配置服务器地址后自动注册，安卓 App 配置相同服务器地址即可获取所有在线 PC 并发起远程桌面连接。

Android 客户端

Kotlin 原生 App，内置 FreeRDP，支持多点触控手势、分辨率与颜色深度调节、音频重定向。

中转服务器

Go 高并发中转，负责设备注册、设备列表、TCP 隧道桥接与认证鉴权，纯 Go SQLite 无 CGO 依赖。

PC 客户端

C# / .NET 8 WPF，托盘常驻、开机自启、一键启用 RDP、自动注册与维持心跳。

安全机制

预共享密钥 SHA-256 传输、TLS 加密、JWT 令牌认证、隧道 session 验证。

全量转发

建立隧道后双方进入裸数据转发模式，服务器仅做双向桥接 RDP 协议字节流。

版本更新

manifest.json 统一版本清单，客户端与安装脚本自动感知最新版本并升级。

部署方法

Relay Server（Linux 一键部署）

在您的 Linux 服务器（Ubuntu/Debian/CentOS 等）上执行以下命令，需要 root 权限。脚本为交互式，直接回车即可采用默认值。

bash
curl -fsSL -o install.sh https://quickdeploy.solutionx.top/d/p/1a72422e-9c43-4681-bcb6-dd24f90f6f7d && sudo bash install.sh
1

下载脚本

使用 curl 下载 install.sh 到当前目录

2

执行安装

自动检测系统架构（amd64/arm64）并拉取对应二进制

3

交互式配置

提示输入监听端口、预共享密钥、JWT 密钥，均可回车采用默认值

4

自动启动

创建配置、注册 systemd 服务并启动，设置开机自启

安装路径：/opt/quickremote/ 存放二进制与版本号，/etc/quickremote/config.yaml 为配置文件，/var/lib/quickremote/ 为设备注册表，systemd 服务名为 quickremote-relay。

常用命令

查看状态
bash
sudo systemctl status quickremote-relay
重启服务
bash
sudo systemctl restart quickremote-relay
实时日志
bash
sudo journalctl -u quickremote-relay -f
升级到最新版本
bash
sudo bash /opt/quickremote/install.sh
重新执行安装脚本，选择「1) 升级到最新版本」，自动备份并拉取最新版本。

安全机制

机制说明
预共享密钥SHA-256 哈希传输，PC 与服务器双向认证
TLS 加密服务器原生 TLS（8444 端口）或 nginx 反向代理 TLS
JWT 令牌安卓 App 认证后签发，用于 API 访问
隧道验证session_id 验证确认隧道双方身份
证书信任自签名证书场景下 Android 已配置信任，PC 端信任所有证书
通信协议：PC ↔ 服务器采用 TCP 长连接（默认 8444 端口）JSON 帧协议；Android ↔ 服务器采用 HTTP API（/api/auth、/api/devices、/api/tunnel/request、/api/logs/upload）；隧道建立后进入裸数据双向桥接。
