# QuickRemote 更新记录

## v1.1.6 (PC客户端)

- 修复自动升级：下载完成后程序退出、但未拉起新版本的问题
- 增强升级脚本健壮性：等待旧进程文件句柄释放时间由 3 秒延长到 5 秒，避免杀软扫描/句柄未释放导致覆盖失败
- 覆盖安装重试次数增加（robocopy /R:3 /W:1 → /R:5 /W:2），文件被占用时多尝试几次
- 升级失败日志固化到 %TEMP%\QuickRemoteUpdate-last.log，便于定位升级失败原因

## v1.1.5 (PC客户端)

- 修复连接服务器后卡在注册：控制连接端口应为 8444（HTTP 端口 +1），此前误配为 8443（HTTP API 端口）导致注册帧发到 HTTP 端口被忽略、无限等待
- 注册阶段新增 10 秒超时：连错端口时快速失败重连并在状态栏提示，不再无限卡住
- 查看日志改为程序内弹窗展示（支持刷新与打开日志目录），不再跳转保存目录
- 默认服务器地址端口由 8443 修正为 8444

## v1.0.13 (Android App)

- 远程桌面连接支持保存用户名和密码：凭据表单新增「保存用户名和密码」选项，勾选后按设备保存凭据，下次连接同一设备时自动预填
- 凭据按设备（device_id）独立存储，不同设备互不干扰；取消勾选后连接将清除该设备已保存的凭据
- 预填时仅在字段为空时填充，避免覆盖用户手动输入

## v1.1.4 (PC客户端)

- 修复「检查更新」提示 404：修正 appsettings.json 中失效的 manifest 分享链接，检查更新恢复正常
- 更新记录只展示 PC 客户端相关内容：过滤掉 Android / 中转服务器等其他组件的条目
- 更新记录窗口滚动条改用主题深色样式（6px 窄轨道、圆角、悬停高亮）

## v1.0.12 (Android App)

- 检查更新新增「确认更新」弹窗：检测到新版本时展示本次更新内容，并提供「立即更新」（跳转下载 APK）与「以后再说」按钮

## v1.0.11 (Android App)

- 修复点击「连接远程桌面」提示 "FreeRDP 连接启动失败"：v1.0.10 误加的 `/sec:negotiate` 参数在 FreeRDP 3.x 中无效（`/sec` 仅接受 rdp|tls|nla|ext，安全协商本就是默认行为），导致参数解析失败、连接无法启动
- 移除 `/sec:negotiate`，保留 `/tls:seclevel:0`（这才是修复 TLS 握手兼容性问题的正确参数）
- 修复失败提示覆盖问题：连接启动失败时不再笼统提示，改为透传具体原因（如"FreeRDP 参数解析失败"），便于排查

## v1.0.10 (Android App)

- 修复远程连接报 "the connection failed at tls connect"（ERRCONNECT_TLS_CONNECT_FAILED）：此前 v1.0.9 误判为 NLA 认证失败，实际该错误发生在更早的 TLS 握手阶段，与凭据无关
- 显式添加 `/sec:negotiate` 并降低 TLS 安全级别（`/tls:seclevel:0`），兼容 Windows RDP 服务较弱的 TLS 密码套件/版本，TLS 握手可正常完成
- 凭据输入界面保留（NLA 认证仍需正确的 Windows 用户名/密码）

## v1.0.9 (Android App)

- 新增 Windows 登录凭据输入：进入远程会话页时先填写用户名/密码（域可选），解决 Windows NLA 认证导致的 TLS 连接失败（"the connection failed at tls connect"）
- 凭据通过 `/u:`、`/p:`、`/d:` 参数传递给 FreeRDP 客户端，完成 NLA 握手后可正常建立远程桌面连接
- 认证失败时表单自动重现并展示具体错误，无需返回重进即可直接重试

## v1.0.3 (中转服务器)

- 新增隧道数据监听器（TCP 8445）：PC 与 App 的 RDP 数据桥接端口此前在已部署的旧版二进制中未监听，导致 App 连接隧道时 ECONNREFUSED（Connection refused）
- 修复 Android/PC 端"连接失败：failed to connect to ... port 8445"问题：升级服务器后 8445 正确监听，隧道数据可正常桥接
- 控制连接端口(8444)原生 TLS 能力保留不变

## v1.0.8 (Android App)

- 修复"FreeRDP 库未加载"：移除 `LibFreeRDP` 中 .so 库不存在的 native 方法调用（如摄像头重定向），避免 static 块抛 `UnsatisfiedLinkError` 导致库加载被判定失败
- 重新构建 APK 并确保 release 产物包含完整的 `libfreerdp-android.so` 及依赖库（arm64-v8a / armeabi-v7a）
- 增强加载失败诊断：界面现在直接显示库加载失败的真实异常原因（如 `dlopen failed: ...`），便于定位

## v1.0.7 (Android App)

- 修复远程连接无法显示画面：重写 `LibFreeRDP` JNI 桥接层为 Java 静态方法实现，与原生 `libfreerdp-android.so` 的回调注册方式完全匹配
- 修复远程连接一直卡在"等待中"：native 通过 `GetStaticMethodID` 调用回调，原 Kotlin `object` 生成实例方法导致回调全部失效，现改为静态方法 + 公有无参构造器，连接状态与画面更新恢复正常

## v1.0.5 (Android App)

- 修复远程连接一直"等待中"：进入会话页自动发起连接（请求隧道 + 启动 FreeRDP），不再停留在 IDLE 状态
- 修复会话认证失败：`RdpSessionManager` 使用独立连接实例，现在自动携带已保存的服务器配置认证，避免因 token 为空导致失败
