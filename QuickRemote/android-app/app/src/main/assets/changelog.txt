QuickRemote Android 更新记录
================================

v1.0.13
- 远程桌面连接支持保存用户名和密码：勾选后按设备保存凭据，下次连接自动预填
- 凭据按设备独立存储，互不干扰；取消勾选后连接将清除已保存凭据
- 预填时仅在字段为空时填充，避免覆盖手动输入

v1.0.12
- 检查更新新增「确认更新」弹窗：展示本次更新内容，提供「立即更新」与「以后再说」

v1.0.11
- 修复连接远程桌面提示 "FreeRDP 连接启动失败"：移除 FreeRDP 3.x 无效的 /sec:negotiate 参数
- 保留 /tls:seclevel:0 修复 TLS 握手兼容性
- 连接失败时透传具体原因，便于排查

v1.0.10
- 修复 "the connection failed at tls connect"：错误发生在 TLS 握手阶段，与凭据无关
- 降低 TLS 安全级别（/tls:seclevel:0），兼容 Windows RDP 较弱的 TLS 密码套件
- 凭据输入界面保留（NLA 认证仍需用户名/密码）

v1.0.9
- 新增 Windows 登录凭据输入：解决 NLA 认证导致的 TLS 连接失败
- 凭据通过 /u: /p: /d: 参数传递给 FreeRDP
- 认证失败时表单自动重现并展示具体错误

v1.0.8
- 修复 "FreeRDP 库未加载"：移除 .so 库不存在的 native 方法调用
- 重新构建 APK 确保包含完整 libfreerdp-android.so 及依赖库
- 增强加载失败诊断，直接显示真实异常原因

v1.0.7
- 修复远程连接无法显示画面：重写 FreeRDP JNI 桥接层为静态方法，与原生库回调完全匹配
- 修复远程连接一直卡在"等待中"：native 回调可正常触发，连接状态与画面更新恢复正常

v1.0.6
- 修复检查更新无法发现新版本：更正内置 manifest 地址，确保能拉取到最新版本清单
- 修复远程连接一直"等待中"：进入会话页自动发起连接（请求隧道 + 启动 FreeRDP）

v1.0.5
- 修复远程连接一直"等待中"：进入会话页自动发起连接（请求隧道 + 启动 FreeRDP）
- 修复会话认证失败：自动携带已保存的服务器配置进行认证，不再停留在等待状态
- 修复会话依赖注入：正确读取服务器地址与预共享密钥

v1.0.4
- 修复"更新记录"按钮点击无反应：补全更新记录弹窗，从 APK 内置资源读取完整更新记录
- 更新记录不再依赖网络，离线也可查看

v1.0.3
- Manifest URL 改为代码内置，无需用户配置
- 修复"检查更新"始终提示"无法获取版本信息"：纠正 manifest 解析模型
- 修复"更新记录"按钮：正确显示更新记录文本
- 修复"上传日志"未认证问题：自动认证
- 设置页版本号跟随实际版本号

v1.0.2
- 修复状态栏遮挡：四个屏幕顶部应用状态栏 insets，内容不再延伸到状态栏
- 改进连接错误提示：显示具体失败原因（密钥不匹配、端口未开放、证书错误等）
- 修复设置页三个按钮不可用：配置真实 manifest 地址、添加加载状态和结果提示
- 集成 FreeRDP 框架：新增 LibFreeRDP JNI、FreeRdpClient、RdpSurfaceView
  - 单指移动/点击、长按右键、双指滚轮、双击打开
  - .so 库未加载时自动降级显示友好提示

v1.0.1
- 修复连接失败无法退出的问题
- 优化设备列表与连接状态展示

v1.0.0
- 首个正式版本：支持服务器配置、设备列表、远程连接
