QuickRemote Android 更新记录
================================

v1.0.25
- 局域网直连优先：与 PC 同网段时自动直连（低延迟），直连失败自动回退中继隧道
- 双指缩放重构：围绕捏合中心缩放、阻尼平滑、平移边界约束，操作更丝滑
- 设置页新增「图像质量（压缩率）」滑块（20-100%），公网连接建议调低减少带宽

v1.0.24
- 修复连接后秒断：进入会话不再强制横屏（改为按钮切换），方向切换不再重建页面，会话保持不断
- 会话启动幂等保护：避免页面重建时重复建立连接

v1.0.23
- 支持键盘输入：点「键盘」按钮弹出软键盘，字符实时发送到远程桌面；支持物理/外接键盘（字母数字、方向键、F1-F12、回车退格等，含 Shift/Ctrl/Alt）
- 会话页横竖屏切换按钮：底部工具栏「旋转」手动切换，不再默认横屏

v1.0.22
- 沉浸全屏展示（隐藏系统栏）
- 支持双指缩放（1x~5x）与双指拖动平移画面
- 触摸操作增强：单指拖动即时移动鼠标、轻点左键、长按右键、双指滑动滚轮
- 设备列表标注连接类型：同网段设备显示「局域网」，其余显示「公网」

v1.0.21
- 设置页新增「重置预共享密钥」：清除已保存密钥与令牌，支持直接修改密钥后重新连接
- 设置页新增「清空日志」：删除本地全部日志文件（带确认提示）
- 预共享密钥输入框支持掩码显示与直接修改

v1.0.20
- 彻底移除 RDP/FreeRDP 实现：删除 FreeRdpClient、RdpSessionScreen、LanDiscovery 及凭据存储
- 移除 39MB 的 FreeRDP native 库，APK 体积大幅缩小
- 设备列表不再显示「内网直连」分区，所有设备统一走截屏方案连接

v1.0.19
- 支持 JPEG 视频帧解码（PC 端无 H.264 编码器时的回退方案）
- 内网直连诊断增强：连接后 10 秒未收到画面时提示「可能停在 Windows 登录界面，请确认凭据」
- 渲染链路日志：记录首帧到达耗时与画面更新，连接失败时自动捕获 FreeRDP native 日志便于定位

v1.0.18
- 修复远程连接一直"等待中"：进入会话页自动发起连接（此前缺少自动触发，导致永远不连接）
- 局域网发现增加诊断日志

v1.0.17
- 修复远程画面黑屏：H.264 SPS/PPS 参数集以 CODEC_CONFIG 标志提交，解码器正确初始化
- 修复连接时序：控制帧先保存分辨率，Surface 就绪后按最新分辨率启动解码器
- 修复双指滚轮误触发：触发阈值提高

v1.0.16
- 新增向日葵式远程桌面：接收 H.264 视频流，MediaCodec 硬件解码渲染（无需 Windows 凭据）
- 新增触摸远程控制：单指移动/点击/长按/双指滚轮，经中继隧道发送到 PC
- 新增内网直连：自动发现同一局域网内的 PC（UDP 8446），FreeRDP 直连 3389（需填凭据）

v1.0.15
- 修正 TLS 握手参数：移除强制 TLS 1.0 的错误配置，改用与 Windows 10/11（TLS 1.2）兼容的协商方式
- 新增「查看日志」功能：设置页可直接查看本地日志并一键复制
- 连接失败提示附加完整错误码，日志级别提升便于排查

v1.0.14
- 修复远程连接 "the connection failed at tls connect"：新增 `/tls:enforce:1.0` 强制 TLS 1.0，兼容 Windows RDP 服务的 TLS 版本（FreeRDP 3.27+ 默认最低 TLS 1.2 导致握手失败）
- 更新记录补全至 v1.0.13 并优化渲染：版本号以主题色高亮显示

v1.0.13
- 远程桌面连接支持保存用户名和密码：勾选后按设备保存凭据，下次连接自动预填
- 凭据按设备独立存储，互不干扰；取消勾选后连接将清除已保存凭据
- 预填时仅在字段为空时填充，避免覆盖手动输入

v1.0.12
- 检查更新新增「确认更新」弹窗：展示本次更新内容，提供「立即更新」与「以后再说」

v1.0.11
- 修复连接远程桌面提示 "FreeRDP 连接启动失败"：移除 FreeRDP 3.x 无效的 /sec:negotiate 参数
- 保留 /tls:seclevel:0 修复 TLS 握手兼容性
- 连接失败时透传具体原因，便于排查

v1.0.10
- 修复 "the connection failed at tls connect"：错误发生在 TLS 握手阶段，与凭据无关
- 降低 TLS 安全级别（/tls:seclevel:0），兼容 Windows RDP 较弱的 TLS 密码套件
- 凭据输入界面保留（NLA 认证仍需用户名/密码）

v1.0.9
- 新增 Windows 登录凭据输入：解决 NLA 认证导致的 TLS 连接失败
- 凭据通过 /u: /p: /d: 参数传递给 FreeRDP
- 认证失败时表单自动重现并展示具体错误

v1.0.8
- 修复 "FreeRDP 库未加载"：移除 .so 库不存在的 native 方法调用
- 重新构建 APK 确保包含完整 libfreerdp-android.so 及依赖库
- 增强加载失败诊断，直接显示真实异常原因

v1.0.7
- 修复远程连接无法显示画面：重写 FreeRDP JNI 桥接层为静态方法，与原生库回调完全匹配
- 修复远程连接一直卡在"等待中"：native 回调可正常触发，连接状态与画面更新恢复正常

v1.0.6
- 修复检查更新无法发现新版本：更正内置 manifest 地址，确保能拉取到最新版本清单
- 修复远程连接一直"等待中"：进入会话页自动发起连接（请求隧道 + 启动 FreeRDP）

v1.0.5
- 修复远程连接一直"等待中"：进入会话页自动发起连接（请求隧道 + 启动 FreeRDP）
- 修复会话认证失败：自动携带已保存的服务器配置进行认证，不再停留在等待状态
- 修复会话依赖注入：正确读取服务器地址与预共享密钥

v1.0.4
- 修复"更新记录"按钮点击无反应：补全更新记录弹窗，从 APK 内置资源读取完整更新记录
- 更新记录不再依赖网络，离线也可查看

v1.0.3

- 修复"检查更新"始终提示"无法获取版本信息"：纠正 manifest 解析模型
- 修复"更新记录"按钮：正确显示更新记录文本
- 修复"上传日志"未认证问题：自动认证
- 设置页版本号跟随实际版本号

v1.0.2
- 修复状态栏遮挡：四个屏幕顶部应用状态栏 insets，内容不再延伸到状态栏
- 改进连接错误提示：显示具体失败原因（密钥不匹配、端口未开放、证书错误等）
- 修复设置页三个按钮不可用：配置真实 manifest 地址、添加加载状态和结果提示
- 集成 FreeRDP 框架：新增 LibFreeRDP JNI、FreeRdpClient、RdpSurfaceView
  - 单指移动/点击、长按右键、双指滚轮、双击打开
