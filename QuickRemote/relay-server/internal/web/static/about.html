QuickRemote

安卓远程连接 Windows 桌面管理工具

项目介绍

QuickRemote 通过自建中转服务器转发 RDP 流量，实现安卓设备远程连接 Windows 桌面。PC 端安装客户端并配置服务器地址后自动注册，安卓 App 配置相同服务器地址即可获取所有在线 PC 并发起远程桌面连接。

安装步骤

  1. 在服务器上运行 install.sh 部署中转服务器
  2. 在 Windows PC 上安装 PC 客户端，配置服务器地址和预共享密钥
  3. 在安卓设备上安装 App，配置相同的服务器地址和预共享密钥
  4. 在 App 中选择 PC 设备，点击连接即可远程桌面

下载

PC 客户端 安卓 App

配置说明

  • 服务器监听端口：默认 8443，可通过配置文件修改
  • 预共享密钥：用于 PC 和安卓 App 认证，请妥善保管
  • TLS 证书：未配置时自动生成自签名证书
  • RDP 端口：默认 3389，确保 Windows RDP 服务已启用
