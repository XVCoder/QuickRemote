
Description:
  Starts an interactive shell with debugging commands to explore a dump

Usage:
  dotnet-dump analyze <dump_path> [options]

Arguments:
  <dump_path>  Name of the dump file to analyze.

Options:
  -c, --command   Runs the command on start. Multiple instances of this parameter can be used in an invocation to chain commands. Commands will get run in the order that they are provided on the command line. If you want dotnet dump to exit after the commands, your last command should be 'exit'.
  -?, -h, --help  Show help and usage information
